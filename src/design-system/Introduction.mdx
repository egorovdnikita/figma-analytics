# Box UI Design System

Дизайн-система десктопного приложения Box UI: токены и переиспользуемые React-компоненты
из `src/components/ui`. Использует Tailwind CSS поверх семантических CSS-переменных —
никаких сырых hex-значений в компонентах.

## Стек

- **React + TypeScript** — компоненты в `src/components/ui/*.tsx`
- **Tailwind CSS** — утилиты, смэппинг токенов в `tailwind.config.ts`
- **CSS custom properties** — источник истины для цвета, тема переключается классом `.dark`
- **Storybook** — эта документация и песочница для компонентов

## Принципы

1. **Семантические токены, не сырые значения.** Компонент никогда не содержит hex-код —
   только `var(--grass)`, `var(--ink)` и т. д. Смотрите вкладку **Токены → Обзор**.
2. **Тема — это класс, не отдельная тема компонентов.** Один и тот же JSX рендерится
   в двух темах за счёт CSS-переменных; переключите тему тумблером в тулбаре сверху.
3. **Скругления по смыслу.** `rounded-chip` (12px) — для чипов и внутреннего сегмента в
   Segmented, `rounded-control` (14px) — для полей ввода, кнопок, IconButton и пунктов навигации,
   `rounded-card` (20px) — для карточек и модалок, `rounded-full` — только для аватаров,
   точек-индикаторов и переключателя Switch.
4. **Минимум вариантов на компонент.** У `Button` пять вариантов (`primary`, `soft`, `outline`,
   `ghost`, `danger`) и три размера — этого достаточно для всего интерфейса приложения,
   новые варианты добавляются только когда реально нужны в продукте.
