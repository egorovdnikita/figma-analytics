# Figma Analytics

Десктопное приложение для macOS и Windows: аналитика рабочего пространства Figma по истории сохранений и обсуждениям — без своего сервера, данные лежат в локальном кэше.

## Что умеет

- **Синхронизация пространства.** Выкачивает проекты, файлы, историю версий и комментарии по всем отслеживаемым командам; повторный синк инкрементальный.
- **Инсайты.** Индекс здоровья, автоматические выводы по порогам, прогноз, аномальные всплески, жизненный цикл файлов, удержание участников по когортам.
- **Дашборд и тренды.** Активность по типам событий, матрица «день недели × час», год к году, календарь активности, движение участников в рейтинге.
- **Люди и обсуждения.** Вклад каждого, пары «кто с кем работает», кто задаёт вопросы и кто отвечает, долг незакрытых комментариев.
- **Файлы и библиотека.** Передачи в разработку по отметкам «Ready for dev», файлы на одном человеке, состав командной библиотеки и темп публикаций.
- **Общие фильтры.** Период, команды, проекты, люди, типы событий, рабочие дни и часы; набор сохраняется как пресет.
- **Командная палитра `⌘K`.** Разделы, файлы, участники, запуск синка; выгрузка всех событий в CSV.
- **Вход через Google.** Только профиль: `openid`, `email`, `profile` — календарь, почту и диск приложение не читает.

## Запуск

Нужен Node 20+ и npm.

```bash
npm install
npm run dev
```

`npm run dev` поднимает Vite и открывает окно Electron с hot reload. Дальше вставь personal access token Figma на экране подключения и добавь команды — шаги в [установке](docs/install.md). Тестов в проекте нет; проверка — `npm run build` (типы и сборка) и `npm run storybook:coverage`.

## Устройство

| Часть                    | Что делает                                               |
| ------------------------ | -------------------------------------------------------- |
| `electron/figma.ts`      | клиент Figma REST API                                    |
| `electron/figmaCache.ts` | синхронизация, дисковый кэш, поток событий, CSV-выгрузка |
| `electron/auth.ts`       | Google OAuth 2.0 PKCE + loopback                         |
| `src/components/figma/`  | разделы, расчёты над потоком событий, графики на SVG     |
| `src/components/ui/`     | компоненты дизайн-системы и их Storybook-истории         |

Renderer не видит токены: все обращения к API идут через IPC в main-процессе. Подробнее — в [устройстве](docs/architecture.md).
