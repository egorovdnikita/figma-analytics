# Box UI

Десктопное приложение для macOS и Windows — личный «цифровой мозг». Первый модуль MVP:
Google Календарь целиком внутри собственного интерфейса.

Стек: Electron 31 · React 18 · TypeScript · Vite · Tailwind CSS v3.

---

## Что умеет

**Календарь**
- Виды: день, неделя, месяц, список (расписание на 30 дней вперёд).
- Все календари аккаунта: свои, общие, подписки. Каждый включается и выключается отдельно.
- События: создание, редактирование, удаление, перенос между календарями.
- Поля события: название, время или «весь день», календарь, повторение, место, участники,
  описание, напоминание, статус занятости, уровень доступа, цвет из палитры Google.
- Участники: список с ответами, ваш RSVP (буду / возможно / не буду) прямо из карточки.
- Поиск по событиям, индикатор текущего времени, выделение мышью для создания события,
  многодневные и повторяющиеся события, ссылка на исходное событие в Google Календаре.
- Автосинхронизация раз в 5 минут и обновление по кнопке.

**Профиль**
- Аккаунт Google: имя, почта, аватар, домен, часовой пояс.
- Выданные разрешения, срок жизни access-токена, наличие refresh-токена.
- Выход и полный отзыв доступа.
- Настройки: тема, вид по умолчанию, первый день недели, формат времени, диапазон часов в сетке,
  показ выходных и отклонённых событий.
- Список всех календарей с ролями доступа, настройки, приехавшие из Google, данные о сборке.

**Интерфейс**
- Светлая и тёмная тема, третий режим — следовать системе.
- Горячие клавиши: `D` день · `W` неделя · `M` месяц · `A` список · `T` сегодня · `C` новое событие ·
  `Esc` закрыть окно.

## Установка

### Вариант 1 — готовый установщик

Соберите его локально (см. ниже) или возьмите артефакты из вкладки **Actions** в GitHub —
workflow `build` собирает `.dmg` для macOS и `.exe` для Windows.

**macOS.** Откройте `.dmg`, перетащите Box UI в Applications. Сборка не подписана Apple ID,
поэтому при первом запуске: правый клик по приложению → **Открыть** → **Открыть**.
Если macOS всё равно блокирует: Системные настройки → Конфиденциальность и безопасность →
«Всё равно открыть».

**Windows.** Запустите `Box UI Setup x.y.z.exe`. SmartScreen покажет предупреждение о неизвестном
издателе: **Подробнее** → **Выполнить в любом случае**.

### Вариант 2 — из исходников

Нужен Node.js 20+ и npm.

```bash
git clone https://github.com/egorovdnikita/box-ui.git
cd box-ui
npm install
npm run dev
```

`npm run dev` поднимает Vite и открывает окно Electron с hot reload.

## Подключение Google

Приложение ходит в Google API напрямую, поэтому нужен собственный OAuth-клиент.
Подробная инструкция: [`docs/google-setup.md`](docs/google-setup.md).

Коротко:

1. [Google Cloud Console](https://console.cloud.google.com/) → новый проект.
2. **APIs & Services → Library** → включить **Google Calendar API**.
3. **OAuth consent screen** → External → заполнить поля → добавить свой Gmail в **Test users**.
4. **Credentials → Create credentials → OAuth client ID → Desktop app**.
5. Client ID и Client Secret вставить в приложение на первом экране — или положить в `.env`:

```bash
cp .env.example .env
```

```
GOOGLE_CLIENT_ID=...apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-...
```

Дальше в приложении — **Войти через Google**. Откроется системный браузер, после подтверждения
вкладка сообщит «Готово», и можно возвращаться в Box UI.

## Как пользоваться

| Действие | Как |
| --- | --- |
| Создать событие | Кнопка «Создать событие», клавиша `C`, или выделите время мышью в сетке дня/недели |
| Создать событие на весь день | Двойной клик по дню в виде «месяц» |
| Открыть событие | Клик по событию в любом виде |
| Изменить или удалить | Открыть событие → «Изменить» / «Удалить» |
| Перенести в другой календарь | Открыть → «Изменить» → сменить календарь → «Сохранить» |
| Скрыть календарь | Чекбокс в списке календарей в сайдбаре |
| Найти событие | Поле поиска в шапке — ищет по всем видимым календарям |
| Сменить тему | Иконка луны/солнца в шапке или экран профиля |
| Перейти к дате | Мини-календарь в сайдбаре |

## Сборка установщиков

```bash
npm run dist:mac    # .dmg (arm64 + x64)
npm run dist:win    # .exe (NSIS, x64 + arm64)
npm run dist        # текущая платформа
npm run pack        # распакованная сборка без установщика, для проверки
```

Готовые файлы появятся в `release/`. Windows-сборку нужно собирать на Windows,
macOS-сборку — на macOS (или через GitHub Actions, workflow уже в репозитории).

## Приватность и безопасность

- Своего сервера у приложения нет: данные ходят только между вашим компьютером и Google.
- Токены хранятся в пользовательской папке приложения и шифруются через `safeStorage`
  (Keychain на macOS, DPAPI на Windows). Путь к папке виден на экране профиля.
- Renderer не имеет доступа к токенам: `contextIsolation: true`, `nodeIntegration: false`,
  все обращения к API идут через IPC в main-процессе.
- Внешние ссылки открываются в системном браузере, навигация внутри окна запрещена.
- Отзыв доступа: экран профиля → «Отозвать доступ».

## Структура

```
electron/          main-процесс
  main.ts          окно, меню, политика навигации
  auth.ts          OAuth 2.0 PKCE + loopback, обновление и отзыв токенов
  google.ts        клиент Google Calendar API
  ipc.ts           IPC-хендлеры
  store.ts         настройки, ключи, зашифрованная сессия
  preload.ts       contextBridge
src/
  state/store.tsx     глобальное состояние
  components/         сайдбар, шапка, виды календаря, диалог события, профиль
    ui/               компоненты дизайн-системы (Button, Input, Modal, ...) + Storybook-истории
  design-system/       токены и обзорная страница для Storybook
  lib/                даты и раскладка событий, цвета, IPC-клиент, повторения
```

## Дизайн-система

Токены и компоненты интерфейса документированы в Storybook.

```bash
npm run storybook        # локально, http://localhost:6006
npm run build-storybook  # статическая сборка в storybook-static/
```

После включения GitHub Pages (Settings → Pages → Source: **GitHub Actions**) актуальная версия
доступна на **https://egorovdnikita.github.io/box-ui/** — деплоится автоматически при пуше
в `main` через [`.github/workflows/storybook.yml`](.github/workflows/storybook.yml).

- Токены (цвет, скругления, тени, типографика): `src/index.css`, `tailwind.config.ts`,
  описаны для документации в [`src/design-system/tokens.ts`](src/design-system/tokens.ts).
- Компоненты: [`src/components/ui`](src/components/ui) — по файлу на компонент,
  рядом лежит `*.stories.tsx`.
- Подробности и принципы — на странице **Введение** в самом Storybook.

Figma не используется: источник истины — код (CSS-переменные + Tailwind), Storybook только
документирует то, что уже есть в приложении.

## Ограничения MVP

Честный список того, чего пока нет:

- Нет офлайн-режима и локального кэша — без сети приложение не покажет события.
- Нет перетаскивания событий мышью для переноса и изменения длительности.
- Редактор повторений — набор пресетов; произвольные RRULE сохраняются, но не редактируются.
- Изменение повторяющегося события применяется к конкретному экземпляру.
- Нет push-уведомлений системы и Google Meet-конференций при создании события.
- Многодневные события в виде «месяц» рисуются отдельным чипом в каждом дне, а не одной полосой.
- Часовой пояс события всегда системный.
