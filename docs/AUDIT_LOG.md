# Журнал аудитов

Формат — из глобальных правил («Аудит на ошибки должен сходиться»). Перед аудитом прочитай журнал: всё, что здесь есть, повторно не поднимай. Повторный аудит — только по diff с последнего аудит-коммита.

## Аудиты

Аудитов на ошибки пока не было: в истории коммитов нет коммитов «Аудит N: …», папки `docs/audits/` нет. Правки после визуальных ревью интерфейса (4–5 августа 2026, `af3c9ae` … `b272756`) — это сверка с макетом, а не аудит на ошибки, в журнал не входят.

### 2026-11-12 — полный аудит, база `43d1c63`

Предыдущего аудита ошибок не было; проверены актуальные описания, main/IPC, хранение данных, OAuth, синхронизация, разделы интерфейса и конфигурация сборок. Следующий аудит — только diff от коммита этой записи (`git log --grep='Аудит 1:'`).

- **P1, кэш отдельно подключённой папки.** Вход: источник `{ id: 'folder', kind: 'project' }`, `filesByProject.folder = [{ key: 'file' }]`, без `projectsByTeam`. Вызов `pruneCache()` при старте удалял список файлов: папка не попадала в `keptProjects`. Офлайн дерево папки становилось пустым. Исправлено: ID источников-папок сразу включены в множество сохраняемых проектов.
- **P1, потеря Google-сессии при временном отказе.** Вход: истёкший access token, существующий refresh token; обновление возвращает HTTP 429 / 503 с JSON-ошибкой. `getAccessToken()` вызывал `clearTokens()` и требовал повторного входа. Исправлено: сессия удаляется при `invalid_grant`, временный отказ возвращает `TOKEN_REFRESH_FAILED`, сохраняя токены.
- **P1, установщики не попадали в артефакты CI.** `electron-builder.yml` пишет в `release.noindex/`, workflow `build.yml` искал `release/*.dmg` и `release/*.exe`. Исправлены оба glob; отсутствие файлов теперь завершает шаг ошибкой. Реальный запуск GitHub Actions для установщиков не выполнялся.
- **Имена и инструкции.** Каноническое имя `figma-analytics` применено в README, паспорте, package metadata, title/meta, меню, OAuth-странице, интерфейсе, Storybook, именах бандла/установщика и инструкции установки. Отдельного web manifest нет. GitHub About после `gh auth status`: `Electron, React, TypeScript, Vite, Tailwind CSS`. Уточнены наличие фоновой синхронизации и пример ссылки на команду. Установщик переносит прежний бандл вместо создания второй установленной копии.
- **Регрессия.** Добавлен `npm test`: кэш отдельно подключённой папки, Google 429/503 и `invalid_grant`, путь артефактов CI. Проверки используют только вымышленные данные, сеть и реальные токены не нужны. `npm test` добавлен в CI перед сборкой Storybook.
- **Проверки по коду.** `npm test`, `npm run build`, `npm run build-storybook`, `npm run storybook:coverage` (9/9), `bash -n scripts/install-macos.sh`, `git diff --check`; `npm audit --omit=dev`: 0 уязвимостей. Это не доказательство отсутствия всех возможных уязвимостей.

## Сознательно не трогаем

- `com.figmaanalytics.desktop`, `window.figmaAnalytics`, IPC-каналы и переменные окружения — технические идентификаторы интеграций.
- Каталог данных `Figma Analytics` и миграционное имя `Box UI` сохраняются для совместимости. Названия внешних Figma-библиотек `Figma Analytics | Tokens`, `Figma Analytics | Primitives`, `Figma Analytics | Icons`, внешних библиотек и исторические материалы не переименовываются.
- Принятая модель хранения Figma-токена: AES-256-GCM с локальным ключом рядом с данными; ограничение явно описано в `docs/privacy.md`.
- На потом: косметический рефакторинг, унификация стиля кода и произвольный редизайн вне рамок этого аудита.
