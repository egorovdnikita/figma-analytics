# Журнал аудитов

Формат — из глобальных правил («Аудит на ошибки должен сходиться»). Перед аудитом прочитай журнал: всё, что здесь есть, повторно не поднимай. Повторный аудит — только по diff с последнего аудит-коммита.

## Аудиты

Аудитов на ошибки пока не было: в истории коммитов нет коммитов «Аудит N: …», папки `docs/audits/` нет. Правки после визуальных ревью интерфейса (4–5 августа 2026, `af3c9ae` … `b272756`) — это сверка с макетом, а не аудит на ошибки, в журнал не входят.

Первый аудит — полный, по всему проекту. Запись добавляй так:

```
### YYYY-MM-DD — коммит <hash>
- Исправлено: P0/P1 — что и где.
- Не подтверждено: …
- На потом: …
```
