# Устройство

Своего сервера нет — данные ходят только между компьютером, Figma и Google, а выкачанная история лежит в локальном кэше. Графики нарисованы вручную на SVG, без chart-библиотек; из зависимостей рантайма — только React, `date-fns`, `clsx`/`tailwind-merge`, иконки и шрифты.

```
electron/            main-процесс
  main.ts            окно, меню, политика навигации
  auth.ts            Google OAuth 2.0 PKCE + loopback, обновление и отзыв токенов
  figma.ts           клиент Figma REST API: аккаунт, проекты, файлы, версии, комментарии, библиотека
  figmaCache.ts      синхронизация, дисковый кэш, поток событий, CSV-выгрузка
  ipc.ts             IPC-хендлеры
  store.ts           настройки, ключи, зашифрованные токены, префы раздела Figma
  preload.ts         contextBridge
src/
  state/store.tsx    глобальное состояние
  components/
    figma/           раздел Figma
      analytics.ts   все расчёты над потоком событий
      charts.tsx     графики на SVG, без внешних библиотек
      *Panel.tsx     разделы: инсайты, дашборд, тренды, люди, обсуждения, файлы, библиотека
    ui/              компоненты дизайн-системы (Button, Input, Modal, ...) + Storybook-истории
  design-system/     токены и обзорные страницы для Storybook
  lib/               IPC-клиент, иконки, шрифты, утилиты
```
