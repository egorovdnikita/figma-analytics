# Ограничения

Честный список того, чего пока нет.

## Figma

- Видно только то, что отдаёт REST API: сохранения версий, комментарии, реакции, библиотека. Просмотров, открытий файла и времени в файле в API нет — значит, нет и в аналитике.
- Синхронизация только ручная: расписания и фонового обновления нет, вебхуки не используются.
- Глубина истории на файл ограничена потолком страниц (по умолчанию 400 × 30 версий). Файлы, упёршиеся в потолок, помечаются как «история подгружена не полностью».
- Комментарии API отдаёт целиком, без пагинации — на очень больших файлах это заметно в первом синке.
- Библиотека читается на уровне команды: видны опубликованные компоненты, наборы и стили, но не использование их в конкретных файлах.
- Токен — personal access token конкретного человека, поэтому пространство видно ровно в тех границах, в которых его видит этот аккаунт.

## Общее

- Календарь, Почта, Диск и Задачи в левой панели — заглушки. Google подключается только ради входа и карточки аккаунта.
- Автообновления приложения нет: новая версия ставится вручную.
