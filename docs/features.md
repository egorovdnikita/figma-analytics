# Возможности

## Figma — аналитика пространства

Figma REST API не отдаёт «просмотры» и «время в файле», зато отдаёт историю сохранений и обсуждения. Приложение выкачивает их по всем командам, разворачивает в единый поток событий и считает аналитику уже поверх него.

**Событие** — это одно из пяти: сохранение версии, комментарий, ответ в обсуждении, закрытие обсуждения, реакция эмодзи. У каждого есть автор, время, файл, проект и команда — дальше любой разрез строится из этих полей.

### Синхронизация

Обход идёт в три фазы с прогрессом: проекты команд → файлы проектов → история версий и комментарии по каждому файлу. Повторный синк инкрементальный: если история файла уже выкачана до конца, страницы листаются только до первой известной версии. Файлы обрабатываются пулом (по умолчанию 4 параллельно), на `429` и `5xx` работает экспоненциальный бэкофф. Списки проектов и файлов кэшируются на 3 минуты, командная библиотека — на 10.

### Разделы

- **Инсайты** — «пульс пространства»: сводный индекс здоровья по факторам, автоматические выводы по порогам (заброшенные файлы, обсуждения без ответа, концентрация, спад активности, ночная работа), прогноз на несколько периодов вперёд, аномальные всплески, жизненный цикл файлов (активен → замедляется → заморожен → мёртв), скорость ответа, признаки переработок, граф связей команды, удержание участников по когортам.
- **Дашборд** — активность по типам событий, число активных людей, текущий период против прошлого, распределение по часам суток и матрица «день недели × час», самые активные файлы, проекты и участники.
- **Тренды** — тренд со сглаживанием, год к году, накопленный объём, календарь активности, сезонность «год × месяц», изменение по типам событий, движение участников в рейтинге (bump-chart) и темп каждого.
- **Люди** — состав команды и вклад каждого, концентрация активности (какую долю делают самые активные), пары «кто с кем работает», динамика состава, карточка участника с его событиями, файлами и матрицей часов. Лишних людей можно скрыть из всей аналитики.
- **Обсуждения** — открыто и закрыто по периодам, кто задаёт вопросы и кто отвечает, реакции, файлы с накопленным долгом незакрытых комментариев.
- **Файлы** — самые нагруженные, файлы с открытыми обсуждениями, отметка о неполной истории; передачи в разработку (отметки «Ready for dev» из Dev Mode) с темпом по файлам; файлы, которые держатся на одном человеке (80%+ сохранений за 90 дней), и кто их держит. Карточка файла показывает последние сохранения и комментарии.
- **Библиотека** — состав опубликованной командной библиотеки (компоненты, наборы вариантов, стили) и авторы публикаций; как часто публикуют компоненты — по отметкам «Components published» в истории файлов, а не только по текущему составу.
- **Активность** — сырая лента всех событий без агрегации, с поиском и фильтром по типам.
- **Настройки** — подключение, рабочий ритм команды, глубина и параллельность синхронизации, плотность интерфейса, пороги инсайтов, статистика кэша, список участников.

### Фильтры и прочее

**Фильтры** общие для всех разделов: гранулярность (день/неделя/месяц/год) или произвольный диапазон, команды, проекты, люди, типы событий, «только рабочие дни» и «только рабочие часы». Набор фильтров сохраняется как пресет.

**Ещё:** командная палитра по `⌘K` (разделы, файлы, участники, запуск синка), закреплённые файлы в сайдбаре, переключение любой карточки в таблицу значений, выгрузка всех событий в CSV.

## Профиль

- Аккаунт Google: имя, почта, аватар, домен.
- Выданные разрешения, срок жизни access-токена, наличие refresh-токена.
- Выход и полный отзыв доступа.
- Настройки: тема, стиль иконок, стиль иконок со стрелками, шрифт.
- Данные о сборке: версия, платформа, Electron/Chromium, путь к хранилищу.

## Интерфейс

- Светлая и тёмная тема, третий режим — следовать системе.
- Разделы приложения переключаются иконками слева: Figma, а также заглушки Календаря, Почты, Диска и Задач — состояние, IPC-слой и дизайн-токены под них уже общие.
- `⌘K` / `Ctrl+K` — командная палитра в разделе Figma.

## Как пользоваться

| Действие                            | Как                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------- |
| Обновить данные Figma               | «Синхронизировать пространство» в шапке раздела или `⌘K`                   |
| Быстро перейти к файлу или человеку | `⌘K` — палитра ищет по разделам, файлам и участникам                       |
| Сузить выборку                      | Панель фильтров: период, команды, проекты, люди, типы событий              |
| Сохранить набор фильтров            | В панели фильтров → сохранить пресет                                       |
| Посмотреть цифры вместо графика     | Переключатель «таблица» на карточке; поведение по умолчанию — в настройках |
| Убрать человека из аналитики        | Настройки → участники, или карточка человека в разделе «Люди»              |
| Выгрузить сырые события             | Настройки → выгрузить CSV                                                  |
| Сменить тему                        | Иконка луны/солнца в рейле слева или экран профиля                         |
